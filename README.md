## Descripción de la actividad

Este repositorio contiene el desarrollo de la actividad correspondiente al primer corte de **Sistemas Inteligentes I**, enfocada en el estudio, implementación y análisis de diferentes algoritmos utilizados para la resolución de problemas en Inteligencia Artificial.

La actividad está dividida en tres temas principales:

- **Búsqueda no informada:** BFS y DFS.
- **Búsqueda informada:** Costo Uniforme (UCS), A* y Beam Search.
- **Búsqueda adversarial:** Minimax y poda Alfa-Beta.

Para cada tema se utilizaron notebooks de Jupyter que contienen explicaciones, ejemplos y ejercicios prácticos. Los algoritmos fueron aplicados a diferentes problemas, como laberintos, recipientes de agua, el 8-puzzle, cuadrículas con obstáculos y el juego de las piedras.

## Ejecución del proyecto

1. Clonar o descargar el repositorio.
2. Abrir una terminal en la carpeta raíz del proyecto.
3. Activar el entorno virtual.
4. Instalar las dependencias necesarias si aún no están disponibles:

```bash
pip install matplotlib jupyter
```

5. Iniciar Jupyter:

```bash
jupyter lab
```

También se puede utilizar:

```bash
jupyter notebook
```

6. Abrir el notebook que se desea revisar y ejecutar sus celdas en orden.

## Uso de Inteligencia Artificial generativa

Durante el desarrollo de la actividad se utilizó **ChatGPT como herramienta de apoyo**, principalmente para complementar el proceso de aprendizaje y facilitar la comprensión de algunos conceptos vistos en clase.

La IA generativa se utilizó para:

- Aclarar conceptos relacionados con BFS, DFS, Costo Uniforme, A*, Beam Search, Minimax y poda Alfa-Beta.
- Explicar el funcionamiento de fragmentos de código y la lógica utilizada por los diferentes algoritmos.
- Recibir sugerencias para modificar, organizar y mejorar algunas implementaciones realizadas durante los talleres.
- Analizar resultados obtenidos durante la ejecución de los algoritmos y apoyar su interpretación.
- Apoyar la redacción y organización de algunas explicaciones y conclusiones incluidas en los notebooks.
- Detectar posibles errores en el código y comprender sus causas antes de realizar las correcciones.

La IA fue utilizada como **herramienta de consulta y acompañamiento**, no como sustituto del desarrollo de la actividad. Las sugerencias recibidas fueron revisadas, adaptadas y probadas antes de incorporarlas al proyecto.

Las integrantes verificaron el funcionamiento del código y revisaron las respuestas y análisis incluidos en la entrega, buscando comprender las soluciones implementadas y su relación con los conceptos estudiados durante el curso.
